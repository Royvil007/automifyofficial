# Automify — AI Employees for Real Estate
**Live:** [automifyofficial.lovable.app](https://automifyofficial.lovable.app)

Marketing site for **Automify Technologies**, presenting the "AI Employees" concept: AI agents that handle the day-to-day operational load for real estate agencies — enquiries, inspections, follow-ups, and payment tracking — so agents keep more of what they sell.

## What's here

Six AI roles, presented as a team an agency can run instead of piecing together separate hires:

- **AI Property Marketing Officer** — runs ads and routes every enquiry to Reception
- **AI Receptionist** — answers every call and message instantly
- **AI Inspection Officer** — books inspections the moment a client's ready
- **AI Property Match Officer** — remembers client preferences and matches new listings automatically
- **AI Installment Officer** — tracks payment plans, flags missed installments before default
- **AI Referral Officer** — turns closed deals into the next referral

## Stack

- React + TypeScript, built with Vite
- Tailwind CSS + shadcn/ui
- Framer Motion for animation
- Deployed on Cloudflare Workers
- Vitest for testing

## Running locally

\`\`\`bash
bun install   # or npm install
bun run dev   # or npm run dev
\`\`\`

Other scripts: \`build\`, \`lint\`, \`test\`, \`preview\`.
